# 独立中文提示词编译器 8210

这是本机冻结 V1 的必要应用源码，供在独立目录部署；不是 ComfyUI 节点。`app/vendor` 保留上游 MIT 许可，来源与固定 commit 见 `app/official_spec.py`。应用其余代码采用本仓库许可。

本目录不包含原工程 data、真实角色档案、历史编译稿、日志、Python 环境或翻译模型。首次启动产生空工程，接收方应在界面创建自己的真实角色档案，不能把空角色表当作编译通过。8207 桥接失败时阻断生成。

创建独立 Python 环境并安装 Argos Translate，按其官方方式安装中文到英文翻译包。翻译模型不随本包分发，须独立核对许可；其状态可在编译器界面检查。服务主体使用 Python 标准库 HTTP 服务。原本机依赖版本与当前验收边界见发布报告。

运行 `./Start-Visible.ps1`；可用 `-Python <独立解释器路径> -Port 8210` 指定解释器及端口。它拒绝占用端口，不会杀死既有服务，使用独立可见控制台、无缓冲输出及失败保留窗口。关闭服务前应先确认没有正在编译的请求。8207 代理目标需与本服务一致；部署后先验证健康、角色、格式校验和中文编译，再进行 GPU 生成。

不要复制本机 data 来部署公开环境，不要将翻译模型、角色素材或日志上传到代码仓库。
