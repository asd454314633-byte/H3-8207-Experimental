3. 六段连续生成流程

每段读取上一段存档的尾部作为受保护前缀，生成后立刻存档并写回执；六段回执都为成功后自动合并。第 4 段做一次 Clean Rebase，切断累积漂移。

旧段复制到 _superseded"] --> RE["只重跑该段及之后"]

前缀合同（每段 i>0，Rebase 段除外）

  • 视频前缀 max|Δ| ≤ 1e-6，音频 ≤ 5e-7
  • p99 ≤ 32 ULP，相关系数 ≥ 0.999999，不随段数累积
  • Rebase 边界必须去相关

提交器七项合同（tools\h3_six_contract）

  • 提交前：段号一致、enabled 正确、项目与前缀一致、链内只差允许变量
  • 每段后：index 恰好 0..i、前缀合同通过、锚定文件存在
  • 任一失败立即停止，不提交下一段

漂移锚定（实验 · 默认关）

  • 节点 H3LatentDriftAnchor，插在采样输出与所有消费者之间
  • 第 1 段记录每类/每通道统计，之后按斜坡回拉均值与高频能量
  • 结论：固定机位近景有效，尚未泛化验证
