# 8210 独立编译器桥接

8207 的六段提示词预览通过 `h3_six_compiler_bridge` 调用独立 8210 服务；预览不提交 ComfyUI GPU 任务。原稿保留，编译失败时由既有前端以原稿直通，并在界面显示实际状态与错误。

桥接通过健康检查确认编译器身份后才调用编译接口。PID 文件默认从节点包位置推导；需要自定义位置时设置 `H3_8210_PID_FILE`。受管任务名为 `H3-8210-Managed`，与 8207 生命周期分离；正式启动器仍可独立使用。不要依赖可见终端存活，也不要启动重复实例。

编译器协议不强制参考图职责、数量或 Subject。图片职责由用户输入决定；桥接不得构造不存在的图片、视频或音频资源。AI 自动导演保持关闭。

测试边界：编译器规则的离线 JavaScript 测试使用接口夹具，不证明在线服务状态。实际在线验收须记录 8210 健康/编译响应、8207 同源页面预览和原稿回退；以上不提交 GPU。
